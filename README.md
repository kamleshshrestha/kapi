# Kapi

Kapi is a small web app for beginner machine-learning learners.

Instead of handing out another generic explanation when a concept doesn't click, it helps learners pinpoint *specifically* what they're misunderstanding — so they can fix the actual gap instead of re-reading the same material.

## Status

A chat-first learning session (explain a concept to Kapi, get a specific diagnosis, work through it with hints and follow-ups) plus flashcards, for six core machine-learning concepts. See `CLAUDE.md` for the architecture.

## Tech Stack

- [Next.js](https://nextjs.org) (App Router)
- React + TypeScript
- Tailwind CSS

## Getting Started

Install dependencies and run the dev server:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
